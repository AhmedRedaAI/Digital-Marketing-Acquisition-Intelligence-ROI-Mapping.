# Digital Marketing Acquisition Intelligence & ROI Mapping

An analytics dashboard designed for growth marketers and digital agencies to monitor cross-channel ad performance, map Return on Investment (ROI), and track budget efficiency.

## 🚀 Live Demo
[View Live App](https://your-username.streamlit.app) <!-- Replace with your actual Streamlit URL -->

## ✨ Features
* **Omni-Channel Performance Matrix**: A centralized, clean data matrix evaluating spend, clicks, revenue, CPC, and ROI across multiple ad networks (Facebook, Google, TikTok, Instagram, Snapchat).
* **ROI Optimization Charts**: Visual breakdown of ROI percentages by marketing channel.
* **Budget vs. Revenue Comparison**: Grouped bar charts comparing the relationship between money spent and revenue generated.
* **Automated Data Insights**: A smart "Top Performer Insight" banner that dynamically extracts and highlights the highest-converting platform.

## 🛠️ Tech Stack
* **Frontend/Framework**: Streamlit
* **Data Processing**: Pandas
* **Data Visualization**: Plotly (Grouped & Bar Charts)
